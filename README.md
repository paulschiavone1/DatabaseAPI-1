# Order Entry Program (Python + Supabase)

A command-line program that creates new orders for existing customers. It
displays customers and products from Supabase, validates user input, saves the
order through the Supabase Data API, and then queries the database again to
verify that the order was saved.

## Files

| File | Purpose |
|---|---|
| `order_entry.py` | Main program (display, input validation, confirmation, insert, verification) |
| `database.py` | Supplied class file: Supabase client and helper functions |
| `config.py` | Supplied class file: reads credentials from `.env` |
| `requirements.txt` | Python dependencies |
| `.env.example` | Template for credentials (placeholders only) |
| `.gitignore` | Excludes `.env` from Git |

## Setup

1. Make sure the class database is already loaded in your own Supabase project
   (tables `customers`, `products`, `orders`).
2. Clone the repository and open the folder in VS Code.
3. Create and activate a virtual environment:

   macOS / Linux:
```
   python3 -m venv .venv
   source .venv/bin/activate
```
   Windows PowerShell:
```
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
```
4. Install dependencies:
```
   python -m pip install -r requirements.txt
```
5. Copy `.env.example` to `.env` and fill in your own credentials:
```
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SECRET_KEY=sb_secret_your_actual_key
```
   The `.env` file is listed in `.gitignore` and is never uploaded to GitHub.

## How to Run

```
python order_entry.py
```

The program will:
1. Show the customers and products from the database.
2. Ask for a customer ID, a product ID, and a quantity (re-asking on invalid input).
3. Show an order summary and ask for confirmation (Y/N).
4. If confirmed, insert the order, then retrieve it from the database and display it.
5. Ask whether to enter another order.

## How It Works

- **Validation:** IDs must be integers that exist in the database. Quantity must
  be a positive whole number. Invalid entries show a message and ask again.
- **Saving:** The order is inserted through the Supabase API using the validated
  IDs and quantity, today's date, and the product's price from the database. The
  order ID is generated by the database.
- **Verification:** After the insert, the program uses the generated order ID to
  run a separate query for that specific order and displays it, with the total
  calculated from the stored `unit_price`. If the query fails or returns nothing,
  the program reports that verification could not be completed and does not
  insert again.
- **Errors:** API failures show a generic message and never print credentials.
